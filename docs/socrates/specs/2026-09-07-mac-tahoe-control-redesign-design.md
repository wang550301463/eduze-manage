## 2. 背景与目标

### 2.1 问题

当前后台视觉偏旧：侧栏/顶栏/按钮/表格/对话框气质不统一，交互密度与反馈不够清晰，用户主观评价「难看」。

### 2.2 目标

在**不改业务逻辑与 API**的前提下，将全站视觉与交互统一为 **macOS Tahoe Control** 气质：

- 系统设置式侧栏与分段控件
- 浅灰底 + 白卡片浮层
- 圆角列表行、轻分隔线、少硬边框
- **主色继续使用现有暖色（陶土红系）**，不用系统蓝作主按钮

### 2.3 非目标

- 不引入新 UI 组件库
- 本轮不做暗色模式（样例 F 仅作参考）
- 不重做信息架构、路由、权限模型
- 不做液态玻璃炫彩背景、Apple 官网大留白风

## 4. 视觉语言

### 4.1 布局

- **侧栏**：约 210px；背景 `#F2F2F7` 系；选中项为**暖色实心胶囊**；分组小标题灰色
- **顶栏**：轻量工具栏（搜索、通知、用户）；无厚阴影
- **主区**：灰底上的白卡片；圆角约 14px；内容区内边距统一

### 4.2 控件

| 控件 | 约定 |
|---|---|
| 主按钮 | 暖色；圆角胶囊或 10–12px 圆角矩形 |
| 次按钮 | 灰底或描边 |
| 分段控件 | 用于「今日/本周」「待审批/已批准」等 |
| 输入 / Select | 浅灰填充、细边框；聚焦暖色 ring |
| 表格 | 表头小字号灰字；行高适中；操作 ghost |
| 对话框 / Sheet | 更大圆角；轻遮罩；取消左 / 主操作右 |
| 空状态 | 短文案 + 一个主 CTA；禁止重复「暂无数据」 |

### 4.3 动效

仅短过渡（侧栏、对话框、hover）。不做花哨材质动画。

### 4.4 导航高亮

保留现有 `navItemEnd`：`/attendance` 与 `/attendance/leaves`、`/courses` 与 `/courses/class-groups` 不得双高亮。

## 5. 改动范围

### 5.1 底座（必做）

- `web/src/styles/globals.css`、`fonts.css`、Tailwind theme tokens
- `web/src/app/shell/*`（Sidebar、Header、MobileNav、CommandPalette 等）
- `web/src/components/ui/*`（Button、Input、Select、Dialog、Drawer/Sheet、DataTable、Toast、Pagination、EmptyState、KPICard 等）
- Login 页

### 5.2 业务页（同一视觉包换皮）

**高频：** 工作台、学员（列表/详情/表单）、签到、请假、周课表、老师可用时段、我的工作台  

**标准：** 课程 / 分组 / 教室、校区 / 账号 / 角色  

页面以调整布局 class 与局部结构为主，**不重写业务逻辑**。

### 5.3 明确不改

- 后端 API、权限、路由结构
- 雪花 ID 字符串传递约定
- 已修复的功能行为（签到、请假、分班展示等）

---

## 6. 实施约束（一次换完下的提交策略）

视觉目标是一次到位，但为可审可回滚，提交建议分波：

1. **令牌 + 全局样式**
2. **壳层（Sidebar / Header / MobileNav）**
3. **基础 UI 组件**
4. **业务页扫尾**（高频优先，标准页同一波完成）

每波结束后本地 `web` build 通过；最终用现有回归账号走通关键路径。

---

## 7. 验收标准

- [ ] 全站控件圆角、间距、字重视觉一致（Tahoe Control）
- [ ] 主按钮 / 侧栏选中为暖色；无系统蓝主按钮
- [ ] 侧栏仅当前项高亮
- [ ] DataTable / 列表空状态不重复
- [ ] 对话框保存后可关闭，且不残留无障碍树节点
- [ ] 桌面与窄屏（侧栏收起 / MobileNav）可用
- [ ] 回归：登录、学员列表与分班展示、签到入园/离园、请假录入、周课表、老师可用时段

---

## 8. 风险

| 风险 | 对策 |
|---|---|
| 改面大、难审 | 按第 6 节分提交；样式层与业务逻辑分离 |
| 回归成本高 | 第 7 节清单强制走完再宣称完成 |
| 视觉回退 | 优先改 `styles` 与 `components/ui`；出问题按文件回滚 |

---

## 9. 成功定义

用户打开后台时，第一眼应像「一台 Mac 上的系统设置式管理 App」：控件清晰、密度合适、暖色品牌仍在，而不是旧版拼盘或蓝主色 Apple 官网仿品。
