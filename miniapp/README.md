# 微信小程序

原生 TypeScript + WXML/WXSS，一个 AppID，老师／家长／游客共用会话。服务端决定访问权；老师／家长切换调用服务端换发角色受限令牌，并清空当前孩子、校区与私有缓存。

## 构建与检查

从仓库根目录运行：

```sh
pnpm --dir web install --frozen-lockfile
node miniapp/build.mjs
pnpm --dir web test src/features/platform/Miniapp.test.ts
```

在微信开发者工具导入 `miniapp/`。编译输出为 `dist/miniapp/`，构建时自动复制 WXML/WXSS/JSON。生成文件不提交。

发布前将 `config.ts` 的 `apiBase` 设置为已登记的 HTTPS 服务域名；将 `project.config.json` 的 `appid` 设置为实际 AppID。订阅消息模板 ID 按后端模板键写入 `config.templateIds`。配置为空会明确报错，不连接模拟服务或伪造登录。

请求 API 的合法域名及 OSS 上传、图片访问域名都需要在微信后台登记。AppSecret、OSS 凭证只能放在服务端。

## 主要流程

- 首页微信登录；家长用前台邀请码提交绑定申请，等待前台审批。
- 老师选择校区进入班级主题，打开学生记录，手机上传过程/成品，保存同一云端草稿，预览后发布。
- 家长选择已授权孩子，查看课表、剩余课时、请假申请和已发布主题课效。
- 消息区独立记录阅读、确认和微信订阅选择。
- 游客查看仍有授权的线上展览、画室介绍、免费活动与商品目录，提交咨询／试听意向；试听名额由前台教务确认。
- 家长查看报告固定版本、整理私人精选作品集，下载展览分享卡和参展证书。
- 老师可录制最长 60 秒原始 MP3，上传失败保留本地文件重试；切换身份或离开页面终止录音。
- 商城支持课程、活动、自提和配送，收件地址保存到订单。真实调用 `wx.requestPayment`，弹窗完成后查询服务端订单，支付与权益／商品交付状态分别展示。
- 订单支持取消、退款申请与售后，失败可重试或刷新状态；同次命令使用稳定幂等键。
- 每份内容最多 100 个唯一媒体文件，含作品图片、视频和音频。

## 验证边界

自动测试覆盖身份/孩子/校区切换清缓存、迟到响应隔离、409 冲突不重试覆盖和 401 撤权。实际拍摄、视频／音频上传与播放、微信登录、订阅消息、微信支付与 iOS/Android 真机体验仍需要画室实际 AppID、域名及 OSS 配置进行验收。
